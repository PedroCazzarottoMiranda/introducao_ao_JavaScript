
# Introdução ao JavaScript

Esta atividade tem como objetivo apresentar os conceitos básicos de JavaScript e sua utilização junto ao HTML.

Durante a atividade, foram estudados conceitos como variáveis (`let` e `const`), tipos de dados, operadores, condicionais (`if` e `else`) e o uso do `console.log()`.

A atividade foi desenvolvida no VS Code, utilizando o navegador para executar e testar os códigos.
