Introdução ao JavaScript

Esta atividade tem como objetivo apresentar os conceitos básicos de JavaScript, uma linguagem de programação utilizada para adicionar interatividade e funcionalidades às páginas HTML.

Durante a atividade, foram trabalhados conceitos como variáveis (let e const), tipos de dados, operadores, condicionais (if e else) e comandos console.log().

A atividade foi desenvolvida utilizando o VS Code e o navegador, com o objetivo de compreender a lógica básica do JavaScript e sua aplicação no desenvolvimento web.
